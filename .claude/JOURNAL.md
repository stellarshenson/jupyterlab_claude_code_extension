12. **Task - Fix waiter that never waited** (v1.0.46): Replace the threshold-based `_INIT_WAITER` with a SIGWINCH-trap + size-change comparison<br>
    **Result**: The borrowed waiter from `jupyterlab_basic_terminal_extension` had `[ "$r" -ge 20 ] && [ "$c" -ge 80 ]`, which is a no-op because `terminado.NamedTermManager.new_terminal` defaults the pty to 24×80 - `c=80 >= 80` passes on iteration 1 and the loop exits without waiting for JL's WebSocket resize. The kernel issues SIGWINCH on the first ioctl from the WebSocket client, so claude now waits for the real size to land.
