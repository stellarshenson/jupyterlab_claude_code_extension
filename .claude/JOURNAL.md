4. **Task - No-shell terminal, search, dangerous-mode** (v1.0.25): Spawn claude as the pty's only process, add fuzzy filter and per-session permission-skip<br>
   **Result**: New backend `LaunchClaudeTerminalHandler` calls `terminal_manager.create(shell_command=[claude, --resume, sid], cwd=...)` so the JL terminal's pty runs claude directly - no bash, no `cd`/`exec` injection. Frontend POSTs to `/launch-terminal` then attaches the widget via `terminal:open`. Added a search input at the panel top with `_normalize` (NFD, strip diacritics, collapse `-_./` whitespace) plus `_fuzzyMatch` doing substring + 5% Levenshtein tolerance (95% threshold) over name/path/display name; the loose subsequence match is gone. `schema/plugin.json` gained `recentLimit` (1-100, default 10) and `dangerouslySkipPermissions` (default false). Per-row context menu picks up a "Resume (Skip Permissions)" item with a Material shield icon (`shieldIcon`, `jp-icon3`) that forces the flag for one click regardless of the global setting. Published 1.0.16, 1.0.19, 1.0.21 to npm and PyPI along the way; local now at v1.0.25.
