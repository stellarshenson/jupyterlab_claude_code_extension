4. **Task - No-shell terminal, search, dangerous-mode** (v1.0.25): Spawn claude as the pty's only process, add fuzzy filter and per-session permission-skip<br>
   **Result**: New backend `LaunchClaudeTerminalHandler` calls `terminal_manager.create(shell_command=[claude, --resume, sid], cwd=...)` so the JL terminal's pty runs claude directly - no bash, no `cd`/`exec` injection. Per-row context menu picks up a "Resume (Skip Permissions)" item with a Material shield icon (`shieldIcon`, `jp-icon3`) that forces the flag for one click regardless of the global setting. Published 1.0.16, 1.0.19, 1.0.21 to npm and PyPI along the way; local now at v1.0.25.

6. **Task - Presentation mode setting** (v1.0.33): Replace the boolean `resolveSessionNames` setting with a tri-state `presentationMode` controlling how rows are labelled<br>
   **Result**: `schema/plugin.json` now exposes `presentationMode` with enum `["session", "folder", "path"]` and default `"session"`. `src/widget.ts` introduces `PresentationMode` type and a `_presentationMode` field; `setPresentationMode` replaces `setResolveSessionNames`. `_displayName` switches on the mode: `session` returns `s.name || basename(project_path)` (old default), `folder` returns the basename, `path` returns `_displayPath(project_path)` which renders relative to the JL `server_root_dir` (absolute when outside it). Path-segment disambiguation in `_disambiguate` still kicks in for `folder` collisions; `path` rows are unique by construction. `src/index.ts` reads `presentationMode` from the settings registry, validates against the enum, and re-applies on `settings.changed`. The old boolean is fully removed - the new tri-state is a strict superset (`session` = old `true`, `folder` = old `false`). Built v1.0.33 via `make install`, `enabled OK`.
