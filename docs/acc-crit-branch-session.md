# Acceptance Criteria - Branch Session

Context-menu action forks the row's current conversation into a new named session using claude's native fork (`claude --resume <current> --fork-session --session-id <new uuid>`), opened in a new terminal. The fork's uuid is generated by the frontend so the name can be stamped once the JSONL appears.

## Notes

- Fork mechanism is claude's own `--fork-session` (battle-tested) rather than a JSONL copy; the cost is that the name can only be stamped after claude writes the file, hence the polling
- Main vs branch has no intrinsic marker in claude's data - "main" is whatever the recency resolution picks; the popup badges it `current`

## API

- `POST launch-terminal` body gains optional `fork_session_id` (requires `session_id`) -> argv `--resume <sid> --fork-session --session-id <fork id>`; 400 `invalid_fork_session_id`
- `POST sessions/set-title` body `{encoded_path, session_id, title}` -> `{ok: true}`; 404 `branch_not_found` while the JSONL does not exist, 400 invalid input
